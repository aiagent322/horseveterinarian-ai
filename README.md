# horseveterinarian-ai

HorseVeterinarian.AI: equine veterinary Q&A directory and resource site (static HTML, 54 pages).

- Hosting: Cloudflare Pages (static HTML, self-hosted fonts in `/fonts`)
- Content: conditions, preventive care, emergency guides, life stages, body systems, disciplines, FAQ, glossary, videos, find-a-vet
- Educational content only; not a substitute for veterinary care
